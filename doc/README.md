# doc/ · 给接入方的实操文档

本目录放**"怎么用起来"的文档**，与 `../docs/` 下的**规范类文档（需求/契约/设计）**分工不同。

| 目录 | 性质 | 内容 |
|---|---|---|
| [`../docs/需求/`](../docs/需求/) | 规范（冻结） | 需求条目与验收标准（`ING-*`） |
| [`../docs/契约/`](../docs/契约/) | 规范（冻结） | 接入点配置、归一化对象、事件名、REST、指令报文 |
| [`../docs/设计/`](../docs/设计/) | 规范（冻结） | 抽仓设计：目录、依赖反转、迁移顺序 |
| **本目录** | 实操指南 | 构建与排障、代码迁移映射、后续的发布与接入指南 |
